# Project Name

This project is a **Clean Architecture** implementation with **CQRS** pattern. All requests and responses are unified using standardized **Request** and **Response** messages to ensure consistency across the application.

## Features

- Clean Architecture layered design  
- CQRS (Command Query Responsibility Segregation) implemented  
- Unified Request and Response messages  
- Easy to extend and maintain  
- Ready for .NET 9
